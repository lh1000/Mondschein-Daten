# Cloud-Umgebung

`setup.sh` richtet eine Claude-Code-Cloud-Sitzung für die App Mondschein ein (Android-SDK, Datendateien,
Python-Pakete). In der Cloud-Umgebung als Setup-Skript eintragen:

```
curl -fsSL https://raw.githubusercontent.com/lh1000/Mondschein-Daten/main/cloud/setup.sh | bash
```

Kopie von `tools/cloud/setup.sh` im App-Repo; dort ändern, dann hierher kopieren.
